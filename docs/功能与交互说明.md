# 作业悬浮球 · 功能与交互说明

> 适用版本：当前开发版（2026-10-29）  
> 平台：Windows 10 1809+ / Windows 11  
> 形态：原生 C++20 / Win32 / GDI+，单 EXE，无网络请求

本文按用户实际操作顺序，说明悬浮球、任务列表、新增/编辑、考试、周期任务、归档、设置和托盘的行为。最后附鼠标/键盘速查和当前限制。

---

## 1. 产品结构

程序只有两个常驻窗口和若干面板视图：

```
桌面悬浮球
   │ 悬停 / 单击
   ▼
主面板（待完成事项）
   ├─ 新增 / 编辑任务
   │    ├─ 作业 / 考试类型切换
   │    ├─ 日期选择器（月历）
   │    └─ 重复规则
   ├─ 归档
   └─ 设置
```

托盘图标常驻，负责显示/隐藏小球、打开面板、设置和退出。

## 2. 桌面悬浮球

### 2.1 显示内容

小球贴在屏幕边缘，默认在右侧。球上显示：

- **剩余天数**：取当前最近截止的一条未完成任务，显示 `N` + `天`。
- **今天**：最近任务今天截止时显示“今天”。
- **逾期**：有逾期任务时，小球变为红色，显示 `!` 和“逾期”。
- **空状态**：没有未完成任务时，显示对勾图标。
- **数量角标**：右上角红色圆点显示未完成任务数量，最多显示 `99+`；只统计未完成，不统计归档。

球的大小、透明度、显示内容和贴边位置都可以在设置里调整。

### 2.2 悬停展开

默认触发方式是“悬停”：

1. 鼠标移到小球上，小球出现发光和手型指针。
2. 停留约 **150ms** 后，待办面板淡入并轻微滑出。
3. 面板出现后，鼠标可以直接移入面板操作。
4. 鼠标离开小球和面板约 **350ms** 后，面板自动收回；如果点了图钉固定，则不会自动收回。

展开动画约 **190ms**，包含透明度淡入和 10px 滑入；收回约 **150ms**。开启“减少动画”后会跳过这些动画。

### 2.3 单击、双击和拖动

| 操作 | 行为 |
| --- | --- |
| 单击小球 | 面板未显示时展开；已显示时收回。**单击不会固定面板。** |
| 双击小球 | 展开面板。 |
| 按住拖动 | 移动小球；移动超过约 3px 判定为拖动，不会误触展开。 |
| 松开拖动 | 自动吸附到最近的屏幕边缘，并保存位置。 |
| 右键小球 | 打开托盘菜单（展开待办、隐藏/显示小球、开机自启、设置、退出）。 |

拖动时如果面板正打开，会先收起面板，避免拖拽过程中面板跟着乱跑。

### 2.4 贴边半隐藏

开启“贴边半隐藏”后，小球会有一部分缩到屏幕边缘外，只露出一部分；鼠标靠近仍可正常展开。该行为只影响视觉，不改变实际可点击区域。

## 3. 主面板

### 3.1 打开和关闭

可以通过以下方式打开：

- 悬停小球（默认）；
- 单击小球；
- 双击小球；
- 托盘菜单“展开待办”；
- 托盘图标双击；
- 第二次启动程序（会唤醒已运行实例并打开面板）。

关闭方式：

- 点击面板右上角 `×`；
- 列表页按 `Esc`；
- 鼠标移开且面板未固定时自动收回。

新增/编辑、日期选择、归档、设置这些子页面会保持面板打开，不会因为鼠标移开而自动收起。

### 3.2 顶部栏

从左到右：

| 控件 | 说明 |
| --- | --- |
| 标题“待完成事项” | 当前列表只显示未完成任务。 |
| `+` | 新增任务；默认进入“新增作业”，可在表单里切换为“考试”。 |
| 图钉 | 固定/取消固定面板。固定后鼠标移开不会自动收起。 |
| 齿轮 | 打开设置。 |
| `×` | 关闭面板（不退出程序）。 |

### 3.3 任务列表

- 只显示**未完成**任务，按截止日期从近到远排序。
- 每行显示：复选框、标题、剩余天数、截止日期、周期标记、编辑铅笔。
- 剩余天数在标题行右侧，使用大号数字：
  - 蓝色 `N 天`：正常；
  - 橙色：今天或明天截止（今天显示“今天”，明天显示橙色 `1 天`）；
  - 红色 `-N 天`：已逾期 N 天；
  - `今天`：今天截止。
- 第二行显示“截止 MM/DD”；周期任务额外显示重复图标和“每天/每周/每月”。
- 考试任务使用紫色标题、左侧紫色竖条和“考试”标签，和普通作业区分。
- 鼠标悬停任务行时整行高亮，并显示手型指针；编辑铅笔单独高亮。
- 列表超过可视高度时可用鼠标滚轮或 `PageUp` / `PageDown` 滚动，右侧有滚动条。
- 列表为空时显示空状态和“添加任务”按钮。

### 3.4 保存失败提示

如果写盘失败，面板顶部会出现提示条。点击提示条会重试保存；成功后提示消失。数据损坏恢复等提示也会显示在这里。

## 4. 任务行操作

### 4.1 完成

以下两种方式都可以完成任务：

- 点击任务标题；
- 点击左侧复选框。

完成后：

1. 标题播放约 **320ms** 的划线动画；
2. 任务标记为已完成并移入归档；
3. 如果是周期任务，自动生成下一次任务；
4. 底部弹出轻提示（Toast），例如“已完成，已移入归档”或“已完成，下次 11/04”。

完成操作不会删除任务，之后可以在归档里恢复。

### 4.2 编辑

点击任务行最右侧的铅笔图标进入编辑表单。表单会带回原来的标题、截止日期、类型和重复规则。

### 4.3 右键菜单

在任务行上点右键，可选择：

| 菜单项 | 行为 |
| --- | --- |
| 编辑 | 打开编辑表单。 |
| 标记完成 | 执行完成流程并归档。 |
| 复制标题 | 把标题复制到剪贴板，并提示“已复制标题”。 |
| 删除 | 弹出确认框；确认后彻底删除，无法恢复。 |

## 5. 新增与编辑任务

### 5.1 打开表单

点击顶部 `+` 或空状态里的“添加任务”，进入“新增作业”。在表单右上角可以切换“作业 / 考试”。

编辑已有任务时，标题会显示“编辑作业”或“编辑考试”。

### 5.2 表单字段

| 字段 | 交互 |
| --- | --- |
| 标题 / 考试名称 | 单行输入，最多 100 个字符；支持中文输入法、光标闪烁、左右移动、Home/End、退格和 Delete。 |
| 类型 | “作业 / 考试”两个胶囊按钮，点击即时切换。考试使用紫色主题。 |
| 截止日期 | 显示完整日期和星期；点击日期区域打开月历。左右 `−` / `+` 按钮按天调整。 |
| 今天 / 明天 / 一周后 | 快捷设置截止日期，当前日期匹配时对应按钮高亮。 |
| 重复 | 点击在“不重复 → 每天 → 每周 → 每月”之间循环；每周会显示具体星期几。考试类型不设置重复。 |
| 保存 | 校验标题非空；保存成功回到列表。 |
| 取消 | 放弃修改，回到列表。 |

标题为空时保存会显示错误提示，例如“请输入作业标题”或“请输入考试名称”。

### 5.3 考试类型

选择“考试”后：

- 表单标题变为“新增考试 / 编辑考试”；
- 标题标签变为“考试名称”；
- 输入框提示变为“例如：高等数学期末考试”；
- 重复字段显示“考试不重复”，不可设置周期；
- 列表中该任务用紫色标题、左侧紫色条和“考试”标签显示；
- 归档中仍保留考试颜色和“考试 · 完成时间”标记。

考试和作业共用同一套截止日期、完成、归档和搜索排序逻辑，不是单独的页面。

### 5.4 键盘操作

| 按键 | 行为 |
| --- | --- |
| `Enter` | 保存表单。 |
| `Esc` | 取消编辑，返回列表。 |
| `←` / `→` | 移动标题光标。 |
| `Home` / `End` | 光标移到标题开头/结尾。 |
| `Delete` | 删除光标后的字符。 |
| `Backspace` | 删除光标前的字符。 |

## 6. 日期选择器

在新增/编辑表单点击日期区域，打开面板内月历。

| 区域 | 交互 |
| --- | --- |
| 标题“选择截止日期” | 当前年月。 |
| `‹` / `›` | 上个月 / 下个月。 |
| 日期网格 | 显示 6 周；相邻月份的日期变灰；点击任意日期选中并返回表单。 |
| 今天 | 选中今天并返回表单。 |
| 取消 | 放弃选择，返回表单。 |
| 左上角返回 | 返回表单。 |
| `Esc` | 返回表单。 |
| `←` / `→` | 切换上/下个月。 |

日期按**自然日**计算，不设置具体时间；今天截止和逾期按本地日历日判断。

---

## 7. 周期任务

新增/编辑时可以把重复设为：

- 每天：下一次 +1 天；
- 每周：下一次 +7 天，表单会显示“每周三”这类文案；
- 每月：下一次加一个月；如果目标月份没有对应日期，会落在该月最后一天。

完成后：

1. 当前任务标记完成并归档；
2. 自动创建下一次任务，标题、类型、重复规则保持一致；
3. 如果下一次日期仍早于或等于今天，会继续向后滚动，直到落在未来；
4. Toast 显示下一次日期。

考试类型不参与周期重复；在表单中切换为考试会清空已设置的重复规则。

---

## 8. 归档

入口：列表底部“查看归档 · N”，或设置里的“查看归档”。

- 只显示已完成任务，按完成时间排序。
- 每行显示标题、完成时间；考试额外显示“考试”标记和紫色标题。
- 左侧恢复图标：把任务恢复为未完成，回到待办列表。
- 右侧删除图标：彻底删除该条归档，弹出确认框。
- 右上角“清空”：清空全部归档，弹出“此操作无法撤销”的确认框。
- 左上角返回或 `Esc`：回到待办列表。
- 归档为空时显示空状态。

| 序号 | 设置 | 控件 | 范围 / 选项 | 说明 |

| 4 | 面板置顶 | 开关 | 开 / 关 | 面板是否保持在普通窗口之上。 |
| 5 | 主题 | 下拉 | 跟随系统 / 浅色 / 深色 | 切换后立即重绘。 |
| 6 | 小球显示内容 | 下拉 | 剩余天数 / 纯图标 | 纯图标时球内显示日历图标。 |
| 7 | 小球尺寸 | 滑块 | 48–64 px | 拖动时实时预览。 |
| 8 | 贴边半隐藏 | 开关 | 开 / 关 | 小球贴边时缩进一部分。 |
| 9 | 减少动画 | 下拉 | 跟随系统 / 强制减少 / 不减少 | 强制减少会关闭展开/收回等动画。 |
| 10 | 小球透明度 | 滑块 | 70%–100% | 拖动时实时预览。 |
| 11 | 面板透明度 | 滑块 | 80%–100% | 拖动时实时预览。 |
| 12 | 重置小球位置 | 操作 | 执行 | 回到主屏右侧默认位置。 |
| 13 | 查看归档 | 链接 | N 项 / 暂无 | 打开归档页。 |

交互细节：

- 开关点击即切换；
- 下拉框点击展开选项，选择后立即生效；点击外部或按 `Esc` 关闭；
- 滑块按住拖动时实时预览，松开后保存；
- 设置页左上角返回或 `Esc` 回到待办列表。

## 10. 托盘与系统行为

### 10.1 托盘

| 操作 | 行为 |
| --- | --- |
| 左键单击托盘图标 | 显示/隐藏悬浮球。 |
| 左键双击托盘图标 | 显示小球并打开待办面板。 |
| 右键托盘图标 | 打开菜单。 |

托盘菜单：

- 展开待办；
- 隐藏小球 / 显示小球；
- 开机自动启动（带勾选状态）；
- 设置…；
- 退出。

### 10.2 单实例

程序使用 `Local\HomeworkFloat.SingleInstance` 互斥量。重复启动不会开第二个进程，而是唤醒已有实例并打开面板。

### 10.3 多显示器与 DPI

- 小球会记住所在显示器，位置按显示器工作区计算；
- 拖动到另一块屏幕后，吸附和面板位置按新屏幕计算；
- 使用 PerMonitorV2 DPI 感知，在 150%/200% 缩放下重新计算尺寸和位置。

### 10.4 跨零点

程序有跨零点定时器。日期变化后会重新计算剩余天数、今天/逾期状态和悬浮球显示，不需要重启。

### 10.5 主题

主题支持浅色、深色和跟随系统。切换后会重新绘制小球和已打开的面板；所有颜色（包括考试紫色、逾期红色、临近橙色）都会随主题适配。

## 11. 动画与反馈

| 场景 | 效果 |
| --- | --- |
| 悬停小球 | 发光渐显 + 手型指针。 |
| 面板展开 | 约 190ms 淡入 + 10px 滑入，三次缓出。 |
| 面板收回 | 约 150ms 淡出 + 滑出。 |
| 任务完成 | 标题划线约 320ms，然后归档。 |
| 保存/恢复/复制 | 底部 Toast 提示，短时间后自动消失。 |
| 悬停任务行 | 整行浅色高亮；编辑铅笔单独高亮。 |
| 标题输入 | 光标闪烁；输入框获得焦点时边框高亮。 |

“减少动画”为“强制减少”时，展开/收回直接显示或隐藏，不做淡入淡出；完成划线等必要反馈保留。

面板绘制对静态背景做了缓存，并复用画布；动画时长和位移没有缩减。

## 13. 数据、备份与恢复

数据目录：

```text
%APPDATA%\HomeworkFloat\
  tasks.json          任务数据
  settings.json       设置
  backups\            每日备份（默认保留最近 7 份）
  logs\app.log        运行日志
```

- 写入采用“临时文件 + FlushFileBuffers + 原子替换”，避免写到一半损坏。
- 每次启动/每日会创建备份；损坏的 `tasks.json` 会被重命名保留，并尝试从备份恢复。
- 写盘失败时面板顶部显示可点击的重试提示。
- 所有数据都在本地，不上传网络。
- 调试时可用 `HF_DATA_DIR` 指向独立测试目录。**注意：使用测试目录启动时，窗口显示的是测试数据，不是真实数据；真实 `%APPDATA%\HomeworkFloat` 不会被修改。**

任务字段包括：`id`、`title`、`dueDate`、`status`、`createdAt`、`completedAt`、`repeat`、`kind`。`kind` 为空或 `homework` 表示作业，`exam` 表示考试。

## 14. 当前限制

- 截止日期只到“日”，不支持具体时间。
- 不支持笔记、优先级、标签、附件。
- 不支持导入/导出、全局快捷键。
- 不支持拖拽排序、周视图、完整日历窗口。
- 周期任务只支持每天/每周/每月，不支持自定义间隔。
- 考试默认不重复；如果确实需要周期性考试，需要另行扩展。
- 清空归档和删除任务不可撤销（删除前有确认框）。

## 15. 典型操作流程

### 添加一条作业

1. 悬停小球，点击面板顶部 `+`。
2. 保持类型为“作业”，输入标题。
3. 点击日期区域，在月历里选择截止日；或用“今天 / 明天 / 一周后”。
4. 需要重复时点击“重复”选择每天/每周/每月。
5. 点击“保存”。

### 添加一场考试

1. 点击 `+`。
2. 点击右上角“考试”。
3. 输入考试名称，选择考试日期。
4. 点击“保存”；列表中该条会以紫色考试样式显示。

### 完成作业

1. 点击任务标题或复选框。
2. 标题划线后自动进入归档。
3. 如果是周期任务，列表里会出现下一次任务。

### 找回已完成任务

1. 点击列表底部“查看归档”。
2. 找到任务，点击左侧恢复图标。
3. 任务回到待办列表。

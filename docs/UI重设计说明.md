## 2. 主要视觉改动

### 悬浮球

- 改为深色玻璃球：深蓝黑渐变、细蓝灰外圈、顶部柔和高光。
- 悬浮态使用青色微光，不扩大球体；逾期态保留红色状态色。
- 数字放大、居中；`天` 作为次级单位；数量角标缩小并改用状态色。
- 半隐藏状态下角标会按屏幕工作区自动收进可见区域，避免被屏幕边缘裁掉。
- 保留原有位置、尺寸、拖拽吸附、半隐藏、透明度和 150ms 悬停逻辑。

### 主面板

- 新增轻量进度区：`今日任务`、`完成数/总数 已完成`、4px 青色进度条。
- 标题栏改为左标题、右图标组；图标统一 16px，Hover 使用低对比青色背景。
- 关闭按钮 Hover 改为红色背景和红色图标；其他图标保持中性 / 青色。
- 面板阴影减弱，圆角统一为 18。

### 任务列表

- 改为 Compact Flat List：去掉逐行卡片边框，行高从 58 收紧到 52。
- 剩余天数放大到 18px：正常蓝色、今天/明天橙色、逾期红色。
- 编辑铅笔在非 Hover 时降到低透明度，Hover 时高亮。
- 考试样式收敛：紫色左侧细条 + `考试 · 截止日期`，标题不再整行紫色，降低紫色面积。
- 完成动画保留 320ms，并增加勾选轻微缩放和文字渐暗。

### 表单 / 月历

- 标题输入框改为 40px 高的深色输入框，聚焦时青色描边。
- 作业 / 考试切换改为分段控件：深色底、选中项深色填充、作业青色边框、考试紫色边框。
- 日期区改为整行日期卡，左侧日历图标，右侧步进按钮；快捷日期保持原有逻辑。
- 月历今天用青色文字 + 圆点，选中日使用青色实心圆，非本月日期降低透明度。

### 设置

- 15 项顺序和交互完全不变，行高收紧到 44。
- 开关改为现代滑动开关；滑块改为青色轨道 + 描边圆点；下拉框为深色弹层。
- 设置标签、数值右对齐，保留滑块拖动实时预览和下拉选择逻辑。

### 反馈

- Toast 改为底部胶囊：深色底、青色勾选图标、全圆角。
- 顶部错误条改为深色背景 + 左侧红色细条，重试点击行为不变。

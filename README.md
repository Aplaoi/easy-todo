# 作业悬浮球（Homework Float）

Windows 桌面作业待办悬浮球。纯原生 C++20 / Win32 / GDI+ 实现，无第三方库、无网络请求，编译产物为单个 EXE。

## 当前版本

这是可运行的初始版本，已覆盖 PRD 中的核心 P0 流程：

- 桌面悬浮球：贴边、拖动吸附、悬停/点击展开、缩放、透明度、半隐藏、多显示器。
- 待办管理：新增、编辑、删除、完成、归档、恢复、清空归档、复制标题。
- 截止日期：按自然日计算，逾期/临近提醒，今天/明天/一周后快捷选择。
- 剩余天数：标题行右侧用大号数字突出“N 天 / -N 天 / 今天”，按临近和逾期变色；第二行保留截止日期。悬浮球显示天数或“今天/逾期”。
- 日期选择器：在新增/编辑面板中点击日期区域打开月历，可选择任意日期。
- 周期任务：新增/编辑时可设为每天、每周、每月；完成后自动生成下一次，原记录进入归档。
- 交互反馈：悬浮球悬停发光 + 手型指针；任务标题悬停手型指针；标题输入框 I 型指针。
- 完成动效：点击任务标题或复选框，标题划掉后归档；每行最右侧的铅笔图标进入编辑。
- 红点计数：右上角红色角标只统计**未完成**作业数量。
- 托盘：显示/隐藏悬浮球、打开面板、设置、退出。
- 数据：`%APPDATA%\HomeworkFloat\`，原子写入、每日备份、损坏恢复、日志轮转。
- 系统：开机自启、置顶、主题跟随、减少动画、单实例、跨零点刷新。
- 设置面板：开关、下拉框和可拖动滑动条，调整后即时预览并保存。

## 构建

需要 Visual Studio 2022（或 MSVC 14.4x）与 Windows 10/11 SDK。

```bat
build.bat
```

脚本会自动调用 `vcvars64.bat`（默认路径 `D:\VisualStudio\VC\Auxiliary\Build\vcvars64.bat`，可按本机安装位置修改），使用 `/MT` 静态 CRT 链接，输出：

```text
build\HomeworkFloat.exe
```

当前构建约 400 KB，满足 PRD 的 ≤2 MB 体积要求。

调试时可在启动前设置 `HF_DATA_DIR` 环境变量，让程序使用独立数据目录，避免影响 `%APPDATA%\HomeworkFloat` 中的真实作业。

## 运行

```bat
build\HomeworkFloat.exe
```

首次运行会创建 `%APPDATA%\HomeworkFloat\tasks.json` 与 `settings.json`，并显示一次托盘提示。

## 操作

| 操作 | 说明 |
| --- | --- |
| 悬停小球 | 发光并展开待办面板（可在设置中改为“仅点击”） |
| 单击小球 | 固定/取消固定面板 |
| 拖动小球 | 移动并自动吸附到屏幕边缘 |
| 点击任务标题 / 复选框 | 划掉并归档 |
| 点击任务行最右侧铅笔 | 编辑该任务 |
| 右键任务 | 编辑、标记完成、复制标题、删除 |
| 点击日期区域 | 打开月历选择截止日期 |
| 点击“今天 / 明天 / 一周后” | 快速设置截止日期 |
| 悬停面板时按 Esc | 返回/关闭 |
| 托盘图标左键 | 显示/隐藏小球 |
| 托盘图标右键 | 菜单 |

## 数据与恢复

- `tasks.json`：作业数据，schemaVersion 1。
- `settings.json`：界面与行为设置。
- `backups\`：每日备份，默认保留最近 7 份。
- `logs\app.log`：运行日志，按大小轮转。

所有写入先写临时文件、`FlushFileBuffers`，再通过 `ReplaceFileW`/`MoveFileEx` 原子替换；损坏文件会被重命名保留，并尝试从备份恢复。保存失败会在面板顶部显示可点击的重试提示。

## 代码结构

```text
src/
  main.cpp      wWinMain、单实例、DPI、GDI+ 生命周期
  app.h/.cpp    窗口、托盘、几何/DPI、动画、消息循环
  panel.cpp     面板布局、列表/表单/月历/归档/设置、鼠标键盘、任务操作
  paint.h/.cpp  GDI+ 双缓冲画布、圆角/文字/阴影/分层窗口呈现
  model.h/.cpp  Task/Settings、日期换算、排序、文案
  store.h/.cpp  加载/保存/备份/恢复/日志
  json.h/.cpp   轻量 JSON 解析与序列化
  common.h      Win32/GDI+ 头、UTF-8 转换、路径工具
  app.manifest  PerMonitorV2、asInvoker、Common Controls v6
```
